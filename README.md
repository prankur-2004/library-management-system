# 📚 Library Management System

A lightweight, modern, and high-performance Single Page Application (SPA) designed to manage books, members, and circulation loans. Built entirely using web standards without external frameworks.

## 🚀 Key Features
* **Dynamic Dashboard:** Real-time tracking of total books, available copies, registered members, and active loans.
* **Inventory Sub-system:** Full CRUD functionality for books with status alerts.
* **Member Management:** Registration desk to maintain patron lists and search through profiles easily.
* **Circulation Engine:** Track book checkouts, dynamic calculation of overdue days, and fine estimation (₹/day).
* **Local Persistence:** Data is securely saved right inside your browser's `LocalStorage` with JSON import/export capabilities.

## 🛠️ Tech Stack
* HTML5 (Semantic Layout)
* CSS3 (Custom Variables, Flexbox/Grid, Glassmorphism blur effects)
* JavaScript (ES6+ array methods, event loop, and modular state architecture)

## 💻 Setup Instruction
Simply clone this repository or download the `index.html` file, and open it in any modern web browser. No installation or complex build pipelines required!
